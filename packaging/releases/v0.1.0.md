First packaged release for Ubuntu 24.04 on amd64. It includes the LogInsight desktop app, CLI, and bundled Atlas demo logs.

Download `loginsight_0.1.0_amd64.deb` and install it from your Downloads directory.

```sh
sudo apt install ./loginsight_0.1.0_amd64.deb
loginsight-gui --sample
```

Open **LogInsight** from your applications menu for an empty session. Use `loginsight --help` for the CLI.
